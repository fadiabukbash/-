# نظام تحليل نتائج الاختبارات – عسقلان EduTech (PWA)

## رفعه على GitHub Pages
1. أنشئ مستودع GitHub جديداً.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع: `index.html` و`manifest.webmanifest` و`sw.js` ومجلد `icons`.
3. من Settings → Pages اختر النشر من `Deploy from a branch` ثم `main` و`/(root)` واضغط Save.
4. انتظر ظهور رابط GitHub Pages وافتحه باستخدام Chrome على Android.
5. استخدم زر «تثبيت التطبيق» الذي يظهر أسفل الصفحة، أو قائمة Chrome → تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.

## ملاحظات
- يجب فتح التطبيق من رابط HTTPS على GitHub Pages حتى يعمل التثبيت.
- ملفات العلامات التي يصدرها المعلم إلى Excel والطباعة تبقى على جهازه، ولا تُرفع تلقائياً إلى GitHub.
- التطبيق يحفظ نسخة من واجهة الموقع الأساسية للتشغيل عند انقطاع الاتصال، لكن بعض المكتبات والخطوط الخارجية تحتاج اتصالاً بالإنترنت.
- لا ترفع ملفات العلامات أو بيانات الطلاب إلى مستودع عام.
